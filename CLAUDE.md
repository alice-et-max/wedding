# Goal

Code a github.io website for a wedding. So ultimately, the "faire-part" should include a QR-code and link.

# Structure

- assets/ : contains all assets for the website (images, etc)
- src/ : code

## Content
1. Count down until the day
2. Presentation
3. Confirm presence : name, surname, email, number of people, their postal address, yes / no, if invited also for diner, they will have a password, and can specify if they can be there for diner as well. Deadline 1st of March. Mail notification everytime someone replies
4. "Liste de voeux" : twint + phone number / RIB ch, fr. The list will contain various items (see https://lovable.dev/preview/tCnvGcuwsYfe48YKJgX8MY724kqcA0r0 as an example), with a price, where people can submit an amount toward paying for this item. The item list should be updatable from a list we maintain.
5. Table layout of diner (people choosing where they seat). This will be deferred for now.
6. Main picture @assets/main_pic.jpeg
7. Wedding photo section (will be empty of course)
